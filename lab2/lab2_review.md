# Лабораторная работа №2

## Вариант 14: Адаптивное монохромное преобразование с усреднением по окну (окно 5×5)

#### Для преобразования полноцветного изображения в полутоновое использовалось взвешенное усреднение каналов RGB:

$$Y = 0.299 \cdot R + 0.587 \cdot G + 0.114 \cdot B$$

#### Адаптивное монохромное преобразование с усреднением по окну

Для каждого пикселя $I(x, y)$ вычисляется средняя яркость в окне $D \times D$:

$$Avg(x, y) = \frac{1}{D^2} \sum_{(r,s) \in \Omega} I(r, s)$$

Решающее правило:

$$Bin(x, y) = \begin{cases} 1, & \text{если } I(x, y) \geq Avg(x, y) \\ 0, & \text{иначе} \end{cases}$$

Для ускорения вычислений использовано **интегральное изображение**, позволяющее получить сумму яркостей в произвольном прямоугольнике за $O(1)$.

В ходе выполнения лабораторной работы были реализованы:

1. **Преобразование RGB → полутон** с использованием взвешенного усреднения по формуле ITU-R BT.601
2. **Адаптивное монохромное преобразование с усреднением по окну** с использованием интегрального изображения для вычисления средней яркости за O(1) на пиксель

   - Малое окно (3×3) — сохраняет мелкие детали, но создаёт шум в однородных областях
   - Среднее окно (5×5, 7×7) — баланс между детализацией и шумом
   - Большое окно (15×15, 25×25, 51×51) — хорошо подавляет шум, но может терять мелкие детали и вносить артефакты на границах областей с разной освещённостью
